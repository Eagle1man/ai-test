# Тест по лабораторным работам

Сайт для сдачи итогового теста. Студент открывает ссылку, вводит ФИО и
группу, отвечает на вопросы и отправляет ответы — отчёт приходит
преподавателю на почту.

**Адрес сайта:** https://eagle1man.github.io/ai-test/

## Как это работает

1. Открыть сайт, ввести фамилию, имя и группу.
2. Ответить на вопросы (прогресс сохраняется в браузере).
3. Нажать «Отправить ответы» — отчёт уйдёт на почту преподавателю.

## Для преподавателя

- Ответы приходят письмом: результат, сводка по лабораторным и подробный
  разбор каждого вопроса.
- Банк вопросов редактируется в `questions.js`.
- Подробная инструкция по настройке и публикации — в `ИНСТРУКЦИЯ.md`.
