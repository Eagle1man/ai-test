# Итоговый тест по лабораторным работам

Статический сайт для **GitHub Pages**. Студент открывает ссылку, вводит
ФИО и группу, отвечает на 28 лёгких вопросов по лабораторным 1–5 и
нажимает «Отправить ответы» — отчёт приходит вам на почту.

## Что лежит в папке

```
Тест_ИИ_сайт/
├── index.html      ← главная страница (её и публикуем)
├── style.css       ← оформление, мобильная вёрстка
├── questions.js    ← банк вопросов (здесь всё редактируется)
├── app.js          ← логика: показ вопросов, проверка, отчёт, отправка
├── package.json
└── разработка/     ← служебные скрипты, на сайт не нужны
    ├── check.js        проверка банка вопросов на ошибки
    ├── e2e.html        прогон сценария в браузере
    └── widthcheck.html проверка вёрстки на узких экранах
```

## Три шага до публикации

### Шаг 1. Настроить отправку писем (обязательно, 3 минуты)

GitHub Pages не умеет сам отправлять письма — это просто файлы на
сервере. Поэтому для отправки используем **Formspree** (бесплатно).

1. Откройте <https://formspree.io> и зарегистрируйтесь на
   **diorlov198611@yandex.ru**.
2. Создайте новую форму («New Form») и укажите адрес получателя —
   тот же `diorlov198611@yandex.ru`.
3. Скопируйте полученный код вида `https://formspree.io/f/xabcdefgh`.
4. Откройте `app.js`, найдите в самом верху:

   ```js
   formEndpoint: "ВСТАВЬТЕ_СЮДА_ВАШ_FORMSPREE_ID",
   ```

   и замените значение на свой код:

   ```js
   formEndpoint: "https://formspree.io/f/xabcdefgh",
   ```

5. На почту придёт письмо с подтверждением — **обязательно откройте
   его и нажмите кнопку подтверждения**, иначе форма не сработает.

Пока это не сделано, сайт работает: после нажатия «Отправить» он
показывает готовый отчёт, который можно скопировать и отправить вручную.

### Шаг 2. Выложить на GitHub

Вариант A — через GitHub Desktop (проще):

1. Скачайте GitHub Desktop, войдите под своим аккаунтом.
2. **File → Add local repository** → выберите папку `Тест_ИИ_сайт`.
3. **Publish repository** (обязательно снимите галочку Private).
4. Откройте репозиторий на GitHub → вкладка **Settings → Pages**.
5. В разделе Source выберите ветку `main`, папку `/ (root)`.
6. Нажмите **Save**. Через минуту сайт откроется по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

Вариант B — через консоль:

```bash
cd Тест_ИИ_сайт
git init
git add .
git commit -m "Тест по лабораторным"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Дальше те же шаги в Settings → Pages.

### Шаг 3. Проверить

Откройте сайт и пройдите тест сам. В отчёте должны появиться ваши ФИО,
группа, результат и разбор по лабораторным. Если пришло письмо на
`diorlov198611@yandex.ru` — всё работает.

## Как выставить оценки

Отчёт приходит письмом в таком виде:

```
Студент: Иванов Иван
Группа: ИС-21
РЕЗУЛЬТАТ: 24 из 28 (86%)
Предварительная оценка: 5

--- ИТОГИ ПО ЛАБОРАТОРНЫМ ---
Лабораторная 1 · Основы применения ИИ: 4/4
Лабораторная 2 · ИИ для информатиков: 3/4
...

--- ПОДРОБНО ---
1. [ВЕРНО] ...
2. [НЕВЕРНО] ... Ответ: 2) Данных оказалось слишком много
```

Предварительная оценка считается автоматически: 85% и выше — «5»,
60–84% — «4», 40–59% — «3», меньше — «2». Это подсказка, итоговую
оценку можно поменять в Moodle или ведомости.

## Как изменить вопросы

Всё в файле `questions.js`. Один вопрос выглядит так:

```js
window.Q({ id: "l4-9", lab: 4, type: "single",
  q: "Какой признак оказался самым важным?",
  hint: "Подсказка под вопросом (можно убрать).",
  options: ["Жанр фильма", "Стоимость билета",
            "Число зрителей", "Страна производства"],
  correct: 0 });
```

Поля:

| Поле | Значение |
|---|---|
| `id` | уникальный номер вопроса, латинскими буквами |
| `lab` | номер лабораторной (1–5) или `0` для итогового блока |
| `type` | `single`, `multi`, `true`, `num` |
| `q` | текст вопроса |
| `hint` | подсказка (необязательно) |
| `options` | варианты ответа |
| `correct` | индекс правильного: `0` для single, `[0,1,2]` для multi |

Порядок вариантов перемешивается автоматически — можно писать
правильный ответ первым, студенты не заметят.

Названия лабораторных меняются в начале `questions.js`, в объекте
`LAB_NAMES`.

## Проверка перед публикацией

```bash
cd Тест_ИИ_сайт/разработка
node check.js
```

Скрипт проверит банк вопросов: пустые тексты, повторяющиеся id,
выход за границы вариантов, ошибки в `app.js` и распределение
правильных ответов. Если в конце «ошибок нет» — всё готово.

## Что не поддерживается

- Несколько попыток: результат один, пересдача — отдельная ссылка.
- Таймер: ограничение по времени задаётся на стороне Moodle.
- Антиплагиат: вопросы из банка видны в коде страницы. Если нужна
  серьёзная защита, используйте банк вопросов Moodle.
